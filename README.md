## 📖 عن التطبيق (About The Project)

**تطبيق زكاتي** هو رفيقك الفقهي والتقني لأداء الركن الثالث من أركان الإسلام بكل يسر وسهولة وموثوقية. صُمم التطبيق بعناية فائقة ليلبي احتياجات كل مسلم ومؤسسة، من خلال توفير حسابات دقيقة ومفصلة لجميع أصناف الأموال الزكوية الخاضعة للشرع المطهر، استناداً إلى الأنصبة الشرعية المعتمدة (نصاب الذهب 85 غرام عيار 24، ونصاب الفضة 595 غرام).

يتميز التطبيق بواجهة مستخدم عربية ساحرة تدعم الاتجاه من اليمين إلى اليسار (RTL)، مع دعم الثيم الفاتح والداكن، وتتبع دقيق لحولان الحول مع تنبيهات ذكية، بالإضافة إلى إمكانية تصدير سجلات وتقارير محاسبية مفصلة بصيغة PDF.

## ✨ المميزات الرئيسية (Key Features)

| الميزة | الوصف |
| :--- | :--- |
| 🧮 **حاسبات زكوية شاملة** | تغطية 9 فئات زكوية فقهية متخصصة (النقود، الذهب، الفضة، عروض التجارة، الزروع، الأراضي، الأنعام، الركاز والمعادن). |
| ⏰ **متابع الحول الذكي (Hawl Tracker)** | تسجيل تاريخ بلوغ النصاب وحساب المدة المتبقية لحولان الحول (هجري وميلادي) مع إشعارات دورية تلقائية. |
| 📄 **تصدير ومشاركة تقارير PDF** | إصدار كشوفات وحسابات زكاة أنيقة وجاهزة للطباعة أو المشاركة الفورية عبر تطبيقات التواصل. |
| 🔒 **أمان وحماية حيوية (Biometrics)** | حماية خصوصية بياناتك المالية وقفل التطبيق عبر بصمة الإصبع أو الوجه ومصادقة محلية مشفرة. |
| 💱 **تعدد العملات والأسعار المخصصة** | دعم العملات الرئيسية (الريال اليمني، السعودي، الدرهم الإماراتي، الجنيه المصري، والدولار) مع تحديث أسعار الذهب والفضة. |
| 🌓 **دعم الوضعين الفاتح والداكن** | تجربة بصرية فائقة الراحة والجمال مصممة بأسلوب Material 3 المتطور. |
| 💾 **قاعدة بيانات محلية سريعة** | حفظ سجلاتك ومفضلاتك محلياً بتقنية Hive السريعة والآمنة دون الحاجة الدائمة للاتصال بالإنترنت. |
| 🤝 **بوابة طلبات المساعدة** | نافذة مخصصة لاستقبال وإدارة طلبات المحتاجين ومستحقي الزكاة ومراجعة بياناتهم بكل شفافية. |

## 📊 الحاسبات الشرعية المتوفرة (Zakat Calculators)

تمت برمجة المعادلات الرياضية والشرعية وفق أدق الفتاوى والضوابط الفقهية:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        منظومة حاسبات زكاتي                             │
├───────────────────┬────────────────────┬───────────────────────────────┤
│ 💰 زكاة النقود     │ 🪙 زكاة الذهب      │ 🥈 زكاة الفضة                 │
│ والودائع والديون  │ بمختلف العيارات     │ والأواني والسبائك             │
├───────────────────┼────────────────────┼───────────────────────────────┤
│ 📈 عروض التجارة   │ 🌾 الزروع والثمار  │ 🐪 الأنعام والمواشي           │
│ البضائع والأرباح  │ مروية بماء المطر/آلات│ إبل، بقر، وغنم بالأسنان الشرعية│
├───────────────────┼────────────────────┼───────────────────────────────┤
│ 🚜 الأراضي        │ ⛏️ المعادن والركاز │ ⭐ المفضلة السريعة            │
│ تجارية أم استثمارية │ الذهب والنفائس والخُمس│ وصول فوري لحاسباتك الشائعة     │
└───────────────────┴────────────────────┴───────────────────────────────┘
```

<details>
<summary><b>🔍 اضغط هنا للتفاصيل الفقهية لكل حاسبة</b></summary>

1. **زكاة الأموال والنقود (`Money Zakat`)**:
   - حساب إجمالي السيولة النقدية + الأرصدة البنكية + الديون المرجوة الاسترداد - الديون العاجلة.
   - المقارنة التلقائية مع قيمة النصاب الشرعي، وإخراج نسبة ربع العُشر (2.5%).

2. **زكاة الذهب (`Gold Zakat`)**:
   - يدعم عيارات (24، 21، 18، وغيرها) مع معادلة التحويل للعيار الصافي.
   - النصاب الشرعي: 85 غرام من الذهب الخالص.
   - استثناء ذهب القنية والزينة المباحة بحسب اختيار المستخدم.

3. **زكاة الفضة (`Silver Zakat`)**:
   - حساب زكاة السبائك والحلي الفضية وفق النصاب الشرعي المعتمد (595 غرام).

4. **زكاة عروض التجارة (`Trade Zakat`)**:
   - تقييم البضائع بسعر البيع الحالي في السوق يوم الحول + النقد المتوفر + الديون المستحقة - الالتزامات المالية العاجلة.

5. **زكاة الزروع والثمار (`Crops Zakat`)**:
   - تحديد نصاب الخمسة أوسق.
   - التمييز الدقيق بين نسب السقي:
     - **10% (العُشر)**: ما سُقي بماء السماء والمطر دون تكلفة.
     - **5% (نصف العُشر)**: ما سُقي بالنواضح والآلات وذوات الكلفة.
     - **7.5%**: السقي المشترك.

6. **زكاة الأنعام والمواشي (`Livestock Zakat`)**:
   - **الإبل**: تبدأ من 5 رؤوس فصاعداً (إخراج شاة، شاتان، بنت مخاض، بنت لبون، حقة، جذعة...).
   - **البقر**: تبدأ من 30 رأساً (تبيع/تبيعة، ومسنة عند كل 40).
   - **الغنم**: تبدأ من 40 شاة (شاة واحدة حتى 120، شاتان حتى 200...).

7. **زكاة الأراضي والعقارات (`Fields Zakat`)**:
   - التفريق بين العقار المعد للبيع والتجارة (تزكى قيمته السوقية كاملة بنسبة 2.5%) وبين العقار المؤجر (تزكى غلته وأرباحه عند توفر الشروط).

8. **زكاة الركاز والمعادن (`Minerals Zakat`)**:
   - استخراج نسبة الخمس (20%) للركاز والدفائن، ونسبة 2.5% للمعادن المستخرجة ذات الكلفة.

</details>

## 🏗️ هيكلية المشروع (Project Architecture)

يعتمد التطبيق هيكلية واضحة ونمطية (Clean Modular Architecture) تعزل منطق إدارة الحالة عن طبقة الواجهات والخدمات الأساسية:

```bash
lib/
├── core/                         # الخدمات المشتركة والثوابت والتهيئة
│   ├── constants/                # ثوابت الألوان، السمات، والأنصبة الفقهية
│   │   ├── app_colors.dart       # لوحة الألوان المعتمدة
│   │   ├── app_themes.dart       # سمات الوضعين الفاتح والداكن
│   │   └── zakat_constants.dart  # القيم الفقهية (الأنصبة والنسب)
│   ├── database/                 # طبقة التخزين المحلي
│   │   ├── local_db_service.dart # قاعدة بيانات Hive السريعة
│   │   └── preferences_service.dart # التفضيلات العامة والإعدادات
│   ├── services/                 # خدمات المنظومة الخارجية
│   │   ├── auth_service.dart     # إدارة جلسات الدخول
│   │   ├── biometrics_service.dart # المصادقة الحيوية والبصمة
│   │   ├── notification_service.dart # جدولة وإطلاق الإشعارات
│   │   ├── pdf_service.dart      # توليد وتنسيق مستندات PDF
│   │   └── permission_service.dart # إدارة أذونات النظام
│   └── utils/                    # دوال مساعدة ومعدلات النصوص والأرقام
│
├── models/                       # نماذج البيانات (Data Models)
│   ├── assistance_request.dart   # نموذج طلبات المساعدة
│   ├── favorite_item.dart        # نموذج العناصر المفضلة
│   ├── user_model.dart           # بيانات المستخدم
│   └── zakat_record.dart         # سجل العمليات الحسابية
│
├── providers/                    # إدارة الحالة (State Management)
│   ├── auth_provider.dart        # حالة المصادقة والأمان
│   ├── favorites_provider.dart   # إدارة الحاسبات المفضلة
│   ├── hawl_provider.dart        # حسابات وتنبيهات الحول
│   ├── notification_provider.dart# إدارة إشعارات الزكاة
│   ├── theme_provider.dart       # تبديل السمة (Light / Dark)
│   └── zakat_provider.dart       # محرك حسابات الزكاة والعملات
│
├── views/                        # شاشات وواجهات المستخدم
│   ├── auth/                     # شاشات تسجيل الدخول والاشتراك
│   ├── calculators/              # شاشات الحاسبات التسع التخصصية
│   ├── dashboard/                # شريط التنقل السفلي والتحكم
│   ├── favorites/                # شاشة الوصول السريع للمفضلات
│   ├── hawl/                     # شاشة متابع الحول والعداد التنازلي
│   ├── home/                     # الشاشة الرئيسية والإحصائيات
│   ├── onboarding/               # الشاشات الترحيبية والتعريفية
│   ├── permissions/              # شاشة طلب أذونات التطبيق
│   ├── requests/                 # شاشة تقديم ومتابعة طلبات المساعدة
│   ├── settings/                 # شاشة الإعدادات العامة والأمان
│   └── splash/                   # شاشة البداية المتحركة
│
└── main.dart                     # نقطة انطلاق التطبيق وتهيئة المزودات
```

## 🚀 طريقة التشغيل والتثبيت (Getting Started)

### المتطلبات المسبقة (Prerequisites)
- تثبيت **[Flutter SDK](https://docs.flutter.dev/get-started/install)** (الإصدار `3.12.0` أو أحدث).
- تثبيت **[Android Studio](https://developer.android.com/studio)** أو **[VS Code](https://code.visualstudio.com/)** مع إضافات Flutter & Dart.
- هاتف فعلي أو محاكي (Emulator) بنظام Android (SDK 21+) أو iOS.

### خطوات التثبيت (Installation Steps)

1. **استنساخ المستودع (Clone Repository):**
   ```bash
   git clone https://github.com/tahaAlasri/ZakatApp.git
   cd final_pro
   ```

2. **تثبيت الحزم والاعتماديات (Install Dependencies):**
   ```bash
   flutter pub get
   ```

3. **التحقق من سلامة بيئة العمل (Check Environment):**
   ```bash
   flutter doctor
   ```

4. **تشغيل التطبيق على المحاكي أو جهازك (Run the App):**
   ```bash
   flutter run
   ```

5. **بناء نسخة الإنتاج (Build APK for Android):**
   ```bash
   flutter build apk --release
   ```

## 🔐 الأمان والخصوصية (Security & Privacy)

- **بياناتك ملكك بالكامل**: جميع الحسابات المالية، السجلات، وتفاصيل الحول تُخزن محلياً على جهاز المستخدم بواسطة قاعدة بيانات `Hive` ولا يتم رفعها أو تداولها خارج الجهاز.
- **القفل الحيوي (Biometric Lock)**: يدعم التطبيق القفل ببصمة الإصبع وبصمة الوجه (`Biometric Authentication`) لحماية مدخلاتك المالية من أي متطفل.
- **أذونات مخصصة**: لا يطلب التطبيق سوى الأذونات الضرورية لتقديم وظائفه (كإذن الإشعارات لتنبيه الحول).
